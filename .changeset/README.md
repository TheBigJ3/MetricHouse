# Changesets

Version and changelog management. Every user-facing change ships with a
changeset describing it.

```
pnpm changeset          # describe your change
pnpm changeset version  # apply, bump versions, write changelogs
```

`metrichouse` and `metrichouse-kit` version independently — the runtime should
be able to stay still while the CLI moves.

Docs: https://github.com/changesets/changesets
